> Git hooks modernos e ultrarrápidos

O Husky melhora seus commits e muito mais 🐶 _au au!_

**Valide mensagens de commit**, **código** e **execute testes** automaticamente ao fazer commit ou push.

Comece [aqui](/pt/get-started.md).

## Funcionalidades

- Apenas `2 kB` (📦 _gzipado_) sem dependências
- Extremamente rápido por ser leve (executa em `~1ms`)
- Usa o novo recurso do Git (`core.hooksPath`)
- Suporte a:
  - macOS, Linux, Windows
  - GUIs do Git, gerenciadores de versão do Node, diretório de hooks personalizado, projetos aninhados, monorepos
  - [Todos os 13 hooks do Git no lado do cliente](https://git-scm.com/docs/githooks)

E mais:

- Hooks por branch
- Use shell POSIX para scripts em casos avançados
- Segue a organização nativa de hooks do Git
- Alinhado com as [boas práticas do npm](https://docs.npmjs.com/cli/v10/using-npm/scripts#best-practices) usando o script `prepare`
- Opções de ativação/desativação
- Pode ser desabilitado globalmente
- Mensagens de erro amigáveis
